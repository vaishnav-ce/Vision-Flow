# 👁️✨ VisionFlow

**VisionFlow** is a real-time, AI-powered adaptive interface that uses computer vision to understand a user’s physical and cognitive state and dynamically adjust the UI for better comfort, focus, and productivity.

> A step toward **human-centric computing**, where the system adapts to the user — not the other way around.

---

## 🚀 Features

* 👁️ **Face Detection** (MediaPipe)
* 📏 **Distance-Based UI Scaling** (auto zoom in/out)
* 🌗 **Ambient Light Detection** (auto Light/Dark mode)
* 🎯 **Focus Detection**

  * Focused
  * Adapting
  * Distracted
* 😴 **Fatigue Tracking** (0–100 scale)
* 👓 **Eye Strain Detection** (Low / Medium / High)
* 🧠 **AI Comfort Advisor**

  * Smart suggestions based on real-time state
* 🤖 **Domain-Specific AI Assistant**

  * No APIs
  * Context-aware responses
* ✨ **Smooth UI Transitions**

  * No flickering
  * Intelligent interpolation

---

## 🛠️ Tech Stack

* **React.js**
* **MediaPipe (Computer Vision)**
* **Vite**
* **Pure Frontend (No Backend)**
* **No external AI APIs**

---

## ⚡ Key Idea

VisionFlow creates a **self-adaptive interface** that responds in real time to:

* User distance from screen
* Ambient lighting conditions
* Face stability & presence
* Cognitive focus level
* Fatigue & eye strain

---

## 🧠 How It Works

1. Webcam captures real-time frames
2. MediaPipe detects face & landmarks
3. System calculates:

   * Distance
   * Brightness
   * Stability
   * Movement
4. Unified logic engine determines:

   * Focus state
   * Fatigue level
   * Eye strain
5. UI adapts dynamically:

   * Scaling
   * Theme
   * Suggestions
   * Visual feedback
